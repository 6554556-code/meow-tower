## Что за проект
Пиксельная игра в духе Tiny Tower: отель для котов. Арт генерирую сама, стиль — уютный детальный пиксель-арт, жирная чёрная обводка.

- **Репозиторий:** https://github.com/6554556-code/meow-tower (публичный, ветка `main`)
- **GitHub Pages:** https://6554556-code.github.io/meow-tower/ (игра), `/privacy.html`, `/support.html` (RU/EN, почта ebookee.app@gmail.com)
- Чистый HTML/CSS/JS, без сборщиков. Локально — двойной клик по `index.html`.
- Один код на все платформы: браузер / Telegram Mini App (отложен) / iOS / (скоро) Android.

capacitor.config.json — appId com.BGGames.MeowTower, webDir www, фон #1b1838
ios/      — Xcode-проект (SPM): только iPhone, только портрет, имя «Мяу Башня»/«Meow Tower» по языку телефона,

Команды: `npm install`, `npm run build` (игра → www/), `npm run ios` (сборка + Xcode), `npm run sync`.

## Задача этого чата: Google Play
Что предстоит (сначала согласовать план со мной!):
1. **Android-проект:** `@capacitor/android` 8.x → `npx cap add android`, папка `android/` в репозиторий. Собирается в **Android Studio, можно на Windows**.
2. **Особенности Android:** кнопка/жест «Назад» (закрывать окошки, а не выходить из игры), вырезы и системные панели (edge-to-edge в новых Android), иконка (адаптивная) и заставка из `assets/icon/app_icon_1024.png` и вывески, только портрет, звук при сворачивании.
3. **Подпись приложения:** ключ загрузки (upload key) — хранить в надёжном месте, не в репозитории. Сборка **AAB**.
4. **Google Play Console:** аккаунт разработчика (личный или организация — у меня есть ИП, в т. ч. армянское; уточнить, что выгоднее). Важно проверить актуальные правила: для новых личных аккаунтов было требование **закрытого теста (12 тестировщиков, 14 дней)** перед выпуском.
5. **Страница в магазине:** иконка 512×512, графический баннер 1024×500, скриншоты, тексты (можно взять из `STORE.md`), политика конфиденциальности (та же ссылка), анкета «Безопасность данных» (данные не собираются), возрастной рейтинг (IARC), целевая аудитория.
