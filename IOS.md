# 🍎 Сборка «Мяу Башни» для iPhone — шпаргалка для Мака

Игра живёт в корне репозитория (как и раньше: GitHub Pages, Telegram).
Для айфона её «упаковывает» **Capacitor** в проект Xcode — он уже лежит в папке `ios/`.

- Bundle ID: `com.BGGames.MeowTower`
- Название под иконкой: «Мяу Башня» (русский телефон) / «Meow Tower» (остальные)
- Только iPhone, только вертикально. Версия 1.0 (1)

---

## Один раз: подготовить Мак

1. **Xcode** из App Store (нужна версия 26 или новее — у тебя уже есть после Шапочки).
2. **Node.js**: открой Терминал, напиши `node -v`.
   Если «command not found» — скачай **LTS** с nodejs.org (файл .pkg), установи, закрой и открой Терминал заново.
3. **Скачать игру** (в Терминале, по одной строке):
   ```
   cd ~/Documents
   git clone https://github.com/6554556-code/meow-tower.git
   cd meow-tower
   npm install
   ```

## Собрать и открыть в Xcode

В Терминале, в папке игры:
```
npm run ios
```
Скрипт сам скопирует свежую игру в приложение и откроет Xcode.

## Первый запуск на твоём айфоне

1. В Xcode слева нажми синюю иконку **App** (самый верх) → в середине выбери **TARGETS → App** → вкладка **Signing & Capabilities**.
2. Галочка **Automatically manage signing** — включена. В **Team** выбери свою команду (ту же, что у Шапочки).
   Xcode сам зарегистрирует Bundle ID `com.BGGames.MeowTower`.
3. Подключи айфон кабелем, сверху в Xcode выбери его в списке устройств.
4. Нажми **▶** (Run). Первая сборка — пара минут.

## Что проверить на телефоне

- [ ] Пиксельный шрифт на месте (и без интернета — включи авиарежим)
- [ ] Верхняя панель и кнопка «Построить» не залезают под чёлку и полоску внизу
- [ ] Музыка играет после первого тапа, замолкает, когда сворачиваешь игру
- [ ] Беззвучный режим (переключатель сбоку) выключает музыку и звуки
- [ ] Сохранение: поиграй, смахни приложение из памяти, открой снова — башня на месте
- [ ] Долгий тап по коту не вызывает меню «Скопировать/Сохранить»

## Когда Claude написал «запушил»

В Терминале, в папке игры:
```
git pull
npm run ios
```
И снова ▶ в Xcode.
